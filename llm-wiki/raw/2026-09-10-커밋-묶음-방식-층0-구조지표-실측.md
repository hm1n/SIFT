# 커밋 묶음 방식 층 0 구조 지표 실측 (2026-09-10)

PR 없는 저장소에서 커밋을 경험 단위로 묶는 방식을 비교하는 첫 층입니다. LLM을 쓰지 않고 방식별
묶음 구조만 잽니다. 판정 기준과 후보 방식은 `wiki/2026-09-10-PR-없는-저장소-커밋-묶음-방식-실험.md`에
있습니다. 이 문서는 실행 조건과 원본 수치만 남깁니다.

## 1. 실행 조건

- 스크립트: `scripts/measure-grouping.mts`. 입력은 `measure-pipeline.ts details --cache=<경로>`가 만든
  `CommitDetail[]` 캐시입니다. 캐시는 블랙리스트 통과분만 담으므로 모든 방식이 같은 커밋 집합을 받습니다.
- 캐시 경로: `C:\Users\user\.cache\demian-grouping\<repo>.json`. 이전 세션의 demian·andbread 캐시는
  남아 있지 않아 네 저장소 모두 이날 새로 떴습니다. `details` phase가 `--cache`를 무시하고 있어
  `fetchDetailsCached`를 타도록 고쳤습니다.
- 시각은 `CommitSummary.date` 하나입니다. author 시각과 commit 시각을 구분하지 않습니다.
- 4-2절 다섯 규칙 중 `path-exact-max8`은 원본 구현이 남아 있지 않아 근사 재현(시간 순 탐욕, 겹치는
  기존 묶음 중 8개 미만인 가장 최근 묶음에 붙임)입니다.

```
GITHUB_TOKEN=$(gh auth token) npx tsx scripts/measure-pipeline.ts <owner> <repo> details --cache=<경로> --concurrency=4
npx tsx scripts/measure-grouping.mts <경로> [--rules=a,b] [--dump=<rule>]
```

## 3. 방식 목록

| 방식 | 축 | 규칙 |
| --- | --- | --- |
| pr-baseline | 기준선 | 현재 프로덕션 `groupCommitsIntoWorkUnits`. PR 없는 커밋은 제외 |
| session-Nh | 1-c | 시간 순 인접 간격이 N시간 이상이면 새 묶음. 파일 신호 없음 |
| path-exact | 4-2 재현 | 정확 경로 겹침 전이 폐쇄 |
| path-exact-max8 | 4-2 재현 | 정확 경로 겹침, 묶음 8개 상한 (근사) |
| path-exact-72h | 4-2 재현 | 정확 경로 겹침이며 72시간 이내인 쌍만 이음 |
| dir-overlap | 4-2 재현 | 디렉터리 겹침 전이 폐쇄 |
| dir-overlap-24h, -6h | 4-2 재현 + 변형 | 디렉터리 겹침이며 N시간 이내인 쌍만 이음 |
| score-tN | 1-a | 시간 순 인접 쌍 점수 ≥ N이면 이음. 간격 ≤2h +2 / ≤24h +1, 경로 겹침 +2 / 디렉터리 겹침 +1, 같은 conventional 접두어 +1, 같은 이슈 번호 +2 |

PR 순도는 PR 소속을 정답으로 둔 커밋 가중 순도입니다. PR 없는 커밋은 각자 고유 라벨로 셉니다. 순위에
쓰지 않고 참고로만 둡니다.
