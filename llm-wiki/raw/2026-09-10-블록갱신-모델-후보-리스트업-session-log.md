# 블록 갱신 모델 후보 리스트업 (이슈 #88)

조사 날짜는 2026-09-10입니다. 블록을 다시 쓰는 호출에 쓸 모델 후보를 요금과 프롬프트 캐싱 단가와 함께 모은 기록입니다. 비교 실측은 별도 세션 로그 `raw/2026-09-10-블록갱신-모델-실측과-캐시-정정-session-log.md`에 있습니다.

## 1. 이 호출의 프로필

- 입력은 고정 근거 스냅샷 5,250토큰에 시스템 프롬프트, 현재 블록, 사용자 답변이 붙습니다. 대략 7,000토큰이고 그중 5,500토큰 정도는 매 턴 같아서 캐시 대상입니다.
- 출력은 상한 900토큰이고 정상 블록은 500~700토큰으로 예상했습니다.
- 다음 질문 앞에 직렬로 놓이므로 첫 토큰 지연이 핵심입니다. 추론 모델은 추론을 끄거나 최저 effort로 써야 합니다.
- 창작 금지가 프롬프트에만 걸려 있으므로 지시 준수력이 가격보다 먼저입니다.

## 2. 조사 방법

Anthropic, OpenAI, xAI, DeepSeek, Mistral의 요금은 공식 요금 페이지에서 직접 확인했습니다. Gemini도 공식 요금 페이지입니다. Qwen과 Amazon Nova는 집계 사이트 수치라 `확인 필요`로 표시했습니다. Groq는 처음 후보에 넣었다가 사용자 지시로 제외했습니다.

회당 추정은 비캐시 입력 1,500토큰, 캐시 읽기 5,500토큰, 출력 600토큰으로 계산한 값이고 실측이 아닙니다. 단위는 백만 토큰당 달러입니다.

## 4. 후보에서 뺀 것과 이유

- gemini-3.5-flash(출력 9.00), gemini-3.1-pro-preview(출력 12.00), Claude Opus 5, Fable 5.1, gpt-5.5, gpt-6-astra, grok-4.6은 출력 단가가 900토큰 출력 호출에 과합니다.
- 추론 전용 모델은 직렬 구조에서 지연을 늘립니다. 추론을 끌 수 있는 모델만 남겼습니다.
- Groq는 사용자 지시로 제외했습니다.

## 5. 비교 대상 선정

사용자가 gpt-5.6-luna와 gemini-3.1-flash-lite 둘을 비교하기로 정했습니다. 전자는 저가 캐시형 가운데 가장 최신 세대이고, 후자는 현행 모델이라 기준선이 됩니다.
