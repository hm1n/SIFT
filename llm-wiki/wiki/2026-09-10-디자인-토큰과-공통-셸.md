# 디자인 토큰과 공통 셸

이슈 #93이 도입한 디자인 토큰과 공통 셸의 현재 계약입니다. 배경은 `wiki/2026-09-10-디자인-개편-계획.md`에, 구현 경위는 `raw/2026-09-10-디자인-토큰과-공통-셸-구현-session-log.md`에 있습니다.

확인 날짜는 2026-09-10입니다.

## 1. 토큰

`src/app/globals.css`의 `:root`에 CSS 변수로 둡니다. 원본은 디자인 파일 `src/index.css`의 `@theme` 블록입니다.

| 묶음 | 변수 | 값 |
| --- | --- | --- |
| 색 9종 | `--color-background`, `--color-card`, `--color-primary-foreground` | `#ffffff` |
| | `--color-foreground`, `--color-primary` | `#0a0a0a` |
| | `--color-muted`, `--color-accent` | `#f5f5f5` |
| | `--color-muted-foreground` | `#737373` |
| | `--color-border` | `#e5e5e5` |
| 보조 회색 | `--color-scrollbar`, `--color-scrollbar-hover` | `#d4d4d4`, `#a3a3a3` |
| 라운드 | `--radius` | `7px` |
| 폰트 | `--font-sans`, `--font-mono`, `--font-pretendard` | Inter, Geist Mono, Pretendard Variable과 각 대체 스택 |
| mono 라벨 | `--label-size-xs`, `--label-size-sm`, `--label-size-md` | `9px`, `10px`, `11px` |
| | `--label-tracking`, `--label-tracking-wide` | `0.1em`, `0.05em` |

이전 이름 `--background`와 `--foreground`는 새 토큰을 가리키는 별칭으로 남겨 두었고 새 코드에서는 쓰지 않습니다. 스크롤바는 전역에서 4px이고 트랙은 투명입니다.

### 폰트 등록

- Inter와 Geist Mono는 `layout.tsx`에서 `next/font/google`로 등록하고 CSS 변수 `--font-inter`, `--font-geist-mono`로 노출합니다. 자체 호스팅이므로 외부 요청이 없습니다.
- Pretendard는 Google Fonts에 없어 jsDelivr CDN 스타일시트를 `<link>`로 넣습니다. 자체 호스팅 여부는 `wiki/2026-09-10-디자인-개편-후속-backlog.md` 7번입니다.

## 2. 셸 컴포넌트

`src/components/shell/`에 있고 `index.ts`가 모아 내보냅니다.

| 컴포넌트 | 역할 | 계약 |
| --- | --- | --- |
| `TopHeader` | 모든 화면 위의 44px 헤더 | `isAuthenticated`가 false면 `Log in with GitHub` 링크, true면 `AccountMenu`를 그립니다. 사용자명은 세션에 없어 그리지 않습니다. |
| `AccountMenu` | 로그인 뒤 계정 메뉴 | 항목은 `Sign out` 하나입니다. 세션 삭제 라우트를 `DELETE`로 부른 뒤 첫 화면으로 이동하고 서버 컴포넌트를 다시 그립니다. 삭제 요청이 실패해도 이동합니다. Escape와 바깥 클릭으로 닫힙니다. |
| `AppShell` | 로그인 뒤 화면의 사이드바 셸 | `repository`의 이름, `owner / name`, 공개 여부와 언어를 그리고 `Change repository` 버튼을 둡니다. Interviews 영역은 빈 상태 문구만 둡니다. 아직 어느 화면도 쓰지 않으며 배치는 #96 이후 화면 이슈가 합니다. |
| `StatusScreen` | Loading, Empty, Error 공용 화면 | `kind`, `code`, `label`, `sub`, `action?`을 받습니다. Error는 `role="alert"`, 나머지는 `role="status"`와 `aria-live="polite"`입니다. 기호 `●`, `○`, `✕`를 코드 앞에 붙여 색 없이도 상태가 갈립니다. `data-status-kind`로 테스트가 상태를 고릅니다. |
| `Button`, `ButtonLink` | 버튼 3종 | `variant`는 `primary`(검정 배경), `secondary`(1px border), `ghost`(텍스트)입니다. `size="large"`가 있습니다. `buttonClassName`으로 클래스만 가져다 쓸 수도 있습니다. |
| `SiftMark`, `GitHubIcon` | 로고와 GitHub 마크 | 디자인 파일의 SVG를 그대로 옮겼고 `currentColor`를 따릅니다. |

## 3. 적용 범위

- `layout.tsx`가 세션 쿠키 유무를 읽어 `TopHeader`를 그립니다. 그래서 layout은 동적으로 렌더됩니다. 첫 화면 page가 이미 쿠키를 읽고 있어 새로 생기는 비용은 없습니다.
- `RepositoryAnalysisView`는 서버가 다시 그려 `hasSession` prop이 바뀌면 렌더 중에 감지해 내부 상태를 맞춥니다. Sign out 뒤 로그인 폼이 남는 것을 막습니다.
- 기존 진입 화면의 색과 카드 모양은 그대로입니다. 재배치는 #94와 #95가 합니다. `page.module.css`는 배경만 토큰으로 바꾸고 헤더 아래 남는 높이를 채우게 했습니다.

## 4. 확인한 것

- 테스트 934개, lint, typecheck 통과.
- dev 서버에서 쿠키 없는 요청과 있는 요청 모두 200이고, 헤더가 각각 로그인 링크와 계정 메뉴를 그렸습니다. 계산된 폰트가 본문 Inter, 라벨 Geist Mono였습니다.

## 5. 확인 필요

- Pretendard CDN이 막힌 환경에서 시스템 폰트로 대체되는지는 보지 않았습니다.
- `AppShell`과 `StatusScreen`은 아직 화면에 배치되지 않아 실제 레이아웃 안에서의 모습은 다음 이슈에서 확인합니다.
