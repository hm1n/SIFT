# 디자인 개편 후속 backlog

`wiki/2026-09-10-디자인-개편-계획.md`가 이번 개편에서 하지 않기로 한 항목과, 하위 이슈를 구현하며 후속으로 분리한 항목을 모읍니다. 새 GitHub 이슈를 만들지 않고 여기에 적습니다.

확인 날짜는 2026-09-10입니다.

## 개편 범위 밖으로 둔 항목

1. **코드 패널의 FILE 모드.** 디자인은 코드 패널에서 DIFF와 FILE 두 모드를 전환합니다. 근거 스냅샷에는 변경 patch만 있고 파일 전체 원문이 없어 API 확장이 먼저 필요합니다. #98은 DIFF 모드만 구현합니다.
2. **사이드바 인터뷰 세션 목록.** 디자인은 사이드바 Interviews 영역에 진행 중이거나 끝난 인터뷰를 나열합니다. 세션 저장 계층이 없어 나열할 데이터가 없습니다. #93은 빈 상태 문구만 둡니다. 세션 저장은 `wiki/2026-08-24-경험선택-세션저장-후속-backlog.md`와 같은 항목입니다.
3. **계정 삭제.** 디자인의 계정 메뉴에 `Delete account`가 있습니다. MVP 범위 밖이고 삭제할 서버 저장 데이터도 없습니다. 계정 메뉴는 `Sign out`만 둡니다.
4. **질문이 참조한 파일만 골라 표시하는 기능.** 디자인은 질문 메시지에 참조 파일 칩을 붙이고 누르면 코드 패널이 그 파일로 이동합니다. 질문 스트림 계약에 참조 파일 정보가 없어 구현할 수 없습니다. 스트림 계약 변경은 인터뷰 질문 생성 쪽 작업입니다.
5. **PAAR 패널의 시각 반영.** #89~#91이 블록 계약을 만든 뒤 그 위에 얹습니다. #98은 오른쪽 열의 자리와 폭만 잡습니다.
6. **다크 테마.** 디자인 파일에 다크 테마가 없습니다. 토큰을 CSS 변수로 두므로 나중에 추가할 수 있지만 지금 만들지 않습니다.

## #93에서 분리한 항목

7. **Pretendard 자체 호스팅.** #93은 디자인 파일과 같은 jsDelivr CDN CSS를 씁니다. 외부 요청 한 건이 추가되고 CDN이 막힌 환경에서는 시스템 폰트로 대체됩니다. `next/font/local`로 바꾸려면 variable woff2 파일을 저장소에 넣어야 하고 첫 로드 용량이 늘어납니다. #95에서 한국어 입력 화면을 만든 뒤 로드 시간을 실측해 판단합니다.
8. **TopHeader의 사용자명과 이니셜.** 세션 쿠키에 GitHub 사용자 정보가 없어 #93은 로그인 여부만 그립니다. #94에서 정했습니다. #94 Constraint가 세션 쿠키 계약을 바꾸지 않는 것이라 쿠키에 사용자 정보를 넣을 수 없고, 남는 방법은 layout에서 매 요청 GitHub `/user`를 조회하는 것인데 모든 페이지에 왕복 한 번이 붙습니다. #94에서는 넣지 않고, Repository 목록 API를 만드는 #95에서 같은 요청에 묶을 수 있는지 판단합니다.
